# 文物期刊论文写作助手 - 产品需求文档

## 1. 产品概述

**文物期刊论文写作助手**是一款帮助研究人员快速生成符合期刊发表规范的文物学术论文的智能工具。通过多轮交互收集文物信息和研究内容，自动生成结构完整、格式规范的学术论文。

**核心价值**：
- 将论文写作时间从数天缩短至分钟级
- 智能匹配期刊格式要求
- 支持单件/批量文物研究

**目标用户**：考古研究人员、文物学者、博物馆工作人员、高校文科师生

## 2. 核心功能

### 2.1 研究模式选择

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **单件研究** | 深入研究一件文物的专题论文 | 重要出土文物、珍贵藏品 |
| **批量研究** | 对比研究多件同批文物 | 窖藏文物、墓葬群出土 |
| **类型研究** | 研究一类文物的演变规律 | 青铜器专题、陶瓷研究 |

### 2.2 信息收集（整合为1个表单）

将原有的3个表单（基础信息+研究内容+作者信息）整合为一个**项目信息表**，分3个Tab切换：

| Tab | 内容 | 必填 |
|-----|------|------|
| 📦 文物信息 | 文物名称、类别、年代、来源、描述、图片 | 必填 |
| 🔬 研究内容 | 研究目的、方法、发现、创新点、目标期刊 | 必填 |
| 👤 作者信息 | 姓名、单位、部门、邮箱、研究方向 | 选填（生成时再填） |

### 2.3 论文生成

- **智能摘要**：自动生成"目的-方法-结果-结论"结构
- **内容扩展**：根据提供的信息自动撰写各章节
- **参考文献**：自动生成符合期刊格式的参考文献

### 2.4 审核校验

| 校验项 | 说明 |
|--------|------|
| 标题格式 | 25字以内，不含标点 |
| 摘要结构 | 目的/方法/结果/结论四段式 |
| 关键词 | 3-8个，中英文对照 |
| 章节结构 | 引言→材料方法→结果→讨论→结论 |
| 图表规范 | 编号、图注位置、分辨率 |
| 参考文献 | 格式统一，数量≥5篇 |

### 2.5 导出功能

- **Word文档**：符合期刊投稿要求
- **PDF文档**：排版后直接打印
- **修订模式**：保留修订痕迹的版本

## 3. 交互流程（优化后：5步）

```
┌─────────────────────────────────────────────────────────────┐
│  步骤1: 欢迎页                                              │
│  - 介绍工具功能                                             │
│  - 选择研究模式（单件/批量/类型）                            │
│  - 点击"开始写作"                                           │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤2: 填写项目信息（Tab表单）                             │
│  - Tab1: 文物信息（可添加多件文物）                          │
│  - Tab2: 研究内容                                           │
│  - Tab3: 作者信息                                           │
│  - 点击"生成论文"                                           │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤3: 生成中                                              │
│  - 显示生成进度                                             │
│  - 实时预览论文框架                                         │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤4: 审核校验                                            │
│  - 左侧: 论文内容预览（可编辑）                               │
│  - 右侧: 格式校验报告 + 修改建议                             │
│  - 底部: 快速修改按钮                                        │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  步骤5: 完成导出                                            │
│  - 论文统计信息                                             │
│  - 导出选项（Word/PDF）                                     │
│  - 分享/继续修改                                            │
└─────────────────────────────────────────────────────────────┘
```

### 流程对比

| 原流程 | 优化后流程 | 改进 |
|--------|-----------|------|
| 8个步骤 | 5个步骤 | 减少38%步骤 |
| 3个独立表单 | 1个Tab表单 | 减少表单切换 |
| 对话+表单混合 | 表单为主，对话辅助 | 更高效 |
| 格式校验单独页面 | 与预览合并 | 一步到位 |

## 4. 界面设计

### 4.1 设计风格

**定位**：典雅学术 · 文化底蕴

| 元素 | 设计规范 |
|------|----------|
| **主色调** | 赭石棕 `#8B5A2B` + 青铜绿 `#4A7C59` |
| **辅助色** | 米白 `#FAF7F2`、墨色 `#1C1917` |
| **点缀色** | 朱砂红 `#C84C31`（用于强调） |
| **字体** | 标题：思源宋体 / 正文：思源黑体 |
| **圆角** | 大圆角 `16px`（卡片）、中圆角 `8px`（按钮） |
| **阴影** | 柔和阴影 `0 4px 20px rgba(0,0,0,0.08)` |
